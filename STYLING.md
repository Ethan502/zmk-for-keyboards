# Keymap Visual Styling Guide

This document explains how to customize the visual appearance of your keymap diagrams generated by keymap-drawer.

## Current Style

Our configuration uses a **modern light theme** inspired by the latest keymap-drawer examples. The style features:

### 🎨 Visual Features
- **Clean white keycaps** with subtle drop shadows
- **Crisp borders** in light gray (#e1e5e9)
- **Modern typography** using system fonts (SF Pro Text, Segoe UI, etc.)
- **Colorful SVG icons** instead of text labels
- **Larger key sizes** (64x64px) for better readability
- **Professional color palette** with semantic colors

### 📱 Color Scheme
- **Keycaps**: White background with light gray borders
- **Held keys**: Light blue accent (#0ea5e9)
- **Text**: Dark slate (#1e293b) for excellent contrast
- **Icons**: Color-coded by function (blue for system, green for media, etc.)

## Icon System

We use a comprehensive SVG icon system with semantic color coding:

### 🔵 System Controls (Blue)
- Bluetooth: `$$bluetooth$$`
- WiFi: `$$wifi$$`
- Home: `$$home$$`
- Settings: `$$settings$$`

### 🟢 Media Controls (Green/Orange)
- Volume Up: `$$vol_up$$`
- Volume Down: `$$vol_down$$`
- Play: `$$play$$` (green)
- Pause: `$$pause$$` (orange)

### 🔴 Alert Functions (Red)
- Mute: `$$mute$$`

### ⚪ Navigation (Gray)
- Arrow keys: `$$arrow_up$$`, `$$arrow_down$$`, `$$arrow_left$$`, `$$arrow_right$$`

### 🌈 RGB/Effects (Colorful)
- RGB Toggle: `$$rgb$$` (rainbow gradient)
- Brightness: `$$brightness$$` (golden)

## Customization Options

### Change Color Theme

Edit `keymap_drawer.config.yaml` in the `svg_style` section:

```yaml
svg_style: |
  .keycap {
    fill: #ffffff;        /* Keycap background */
    stroke: #e1e5e9;      /* Border color */
  }
  .keycode {
    fill: #1e293b;        /* Text color */
  }
```

### Alternative Themes

#### Dark Theme
```yaml
.keycap {
  fill: #374151;
  stroke: #6b7280;
}
.keycode {
  fill: #f9fafb;
}
```

#### Minimal Theme
```yaml
.keycap {
  fill: #ffffff;
  stroke: #d1d5db;
  stroke-width: 1;
  filter: none;  /* Remove shadows */
}
```

#### Colorful Theme
```yaml
.keycap.layer-0 { fill: #fef3c7; }  /* Base layer - yellow */
.keycap.layer-1 { fill: #dbeafe; }  /* Layer 1 - blue */
.keycap.layer-2 { fill: #fecaca; }  /* Layer 2 - red */
```

### Add Custom Icons

Add new SVG icons in the `glyphs` section:

```yaml
glyphs:
  custom_icon: |
    <svg viewBox="0 0 24 24">
      <path fill="#your-color" d="your-svg-path"/>
    </svg>
```

Then use in key mappings:
```yaml
raw_binding_map:
  "&my_custom_key": "$$custom_icon$$"
```

## Testing Changes

After modifying `keymap_drawer.config.yaml`:

1. **Commit and push** your changes
2. **GitHub Actions** will automatically generate new SVGs
3. **Check results** in the `keymap-drawer/` directory
4. **Iterate** until you're happy with the appearance

## Troubleshooting

### Icons Not Showing
- Check SVG syntax in `glyphs` section
- Ensure icon names match in `raw_binding_map`
- Verify YAML indentation

### Colors Not Applied
- Check CSS selector names
- Ensure proper YAML string formatting with `|`
- Test with simple color changes first

### Layout Issues
- Adjust `key_w`, `key_h` for key sizes
- Modify padding values for spacing
- Check `key_font_size` for text scaling
